# 指标口径（唯一来源）

> 报告里每个数字怎么来的，**只认这份文档**。代码里的公式与本文档不一致时，以本文档为准并修代码。

## 一、席位统计画像（`seat_profile.py::compute_profile`）

观察窗口：默认 `--lookback 120` 日历天（用交易日历截取真实交易日）。

| 指标 | 公式 / 定义 | 读法 |
|---|---|---|
| `n_days` / `n_stocks` | 窗口内上榜天数 / 覆盖股票数 | 活跃度 |
| `buy_amt` / `sell_amt` / `net_amt` | 区间买/卖/净买总额（万元，**已按四元组去重**，见 api_sources §3） | 资金体量 |
| `avg_buy_per_day` | `net_amt / n_days` | 日均净投入 |
| `avg_chg_on_day` | 上榜日个股平均涨跌幅 % | **打板 vs 低吸的判别基础** |
| `board_rate` | 上榜日个股涨幅 ≥ 9.5% 的比例 | 越高越像打板 |
| `win_1d` / `avg_1d` | 只用 `ACT_BUY>0` 的记录，`D1_CLOSE_ADJCHRATE` 非空的上涨概率 / 平均涨幅 | **次日溢价能力**；当日买入的 D1 为 null，自动排除 |
| `win_5d` / `avg_5d` | 同上，5 日 | 中期溢价 |
| `quick_flip_rate` | 买入日之后**下一交易日**该席位即在同股出现净卖出的比例 | 「一日游」程度 |
| `median_hold_days` | 买入日 → 该席位下一次在同股出现的**交易日**间隔中位数，截断 30 | 持股周期 |
| `net_bias` | `net_amt / (buy_amt + sell_amt)` ∈ [-1,1] | ≥0.3 净买方；≤-0.3 净卖方 |
| `official_backtest` | 东财 `RPT_TRADE_BACK_PROFILE` 近三月行的次日/5日胜率 | 与自算 `win_1d` 交叉验证，不一致时两者都展示、不强行调和。⚠ **单位注意：官方字段是百分数**（`rise_prob_1d: 50` = 50%），自算 `win_1d` 是 0~1 小数，报告里分别格式化，别混 |

### 风格标签推断（`infer_style`，规则写死）

| 标签 | 条件 |
|---|---|
| 净买方 / 净卖方 / 双向对倒 | `net_bias` ≥ 0.3 / ≤ -0.3 / 其他 |
| 打板倾向 | `avg_chg_on_day` ≥ 5 且 `board_rate` ≥ 0.4 |
| 低吸倾向 | `avg_chg_on_day` ≤ 1 |
| 半路/接力 | 其余 |
| 一日游 | `quick_flip_rate` ≥ 0.5 |
| 波段/趋势 | `quick_flip_rate` ≤ 0.15 且 `median_hold_days` ≥ 3 |
| 次日溢价强 / 弱 | `win_1d` ≥ 0.6 / ≤ 0.4 |

### 已知取舍（报告里要敢写）

* `quick_flip_rate` 用「下一交易日是否净卖出」近似，**做 T / 对倒席位会高估**；
* 区间末端的买入，其后验字段可能没走完 → 按非空过滤，天然损失最新几天样本；
* 单席位样本 < 10 条时，胜率数字波动极大，报告标注样本量。

## 二、单股榜单还原与席位归集（`stock_analysis.py`）

单票分析的入口口径。数据源：`RPT_DAILYBILLBOARD_DETAILSNEW`（股票×日×上榜原因）
+ `RPT_BILLBOARD_DAILYDETAILSBUY` / `...SELL`（买五/卖五），原始字段见 api_sources §6。

### 2.1 榜单分组

| 概念 | 定义 |
|---|---|
| 榜单签名 | `(BILLBOARD_BUY_AMT, BILLBOARD_SELL_AMT)`，金额相同 ⇒ **同一份榜单** |
| 榜单 | 同一签名下的所有上榜原因合并成一份榜单；多份榜单按 `BILLBOARD_DEAL_AMT` 降序编号 B1、B2… |
| `is_cumulative` | 上榜原因含「连续三个交易日」或「累计」⇒ 3 日累计榜（统计区间覆盖 3 个交易日，与单日榜**重叠**） |
| 买五 / 卖五 | 每个上榜原因各一套买入前五/卖出前五；同原因内按 `(席位代码, 金额)` 去重后**显式按金额降序**取 5 |

**自洽校验**：买入前五金额合计 = 榜单买额；卖出前五合计 = 榜单卖额（实测逐分吻合）。

### 2.2 席位级口径

| 指标 | 定义 |
|---|---|
| 席位本次买入/卖出 | 该席位在**该榜单**买榜金额 / 卖榜金额之和（按 seat_code+名称聚合） |
| 席位本次净额 | 买榜金额 − 卖榜金额。**不使用东财 NET 字段**（口径矛盾，见 api_sources §6.2） |
| `overlap` | 该席位横跨多份榜单（区间可能重叠）⇒ 只按榜单分别列示，**不做合计解读** |
| `is_channel` | 席位代码 ∈ {`0`（机构专用）} 或名称含「机构专用」⇒ 无个股历史可查，只给知识库先验 |
| `同榜双向` | 该席位名同时出现在同一榜单的买榜与卖榜 |

### 2.3 该股历史上榜后表现（`stock_history_stats`）

* 同一日期多行只取**一行**：优先单日榜（非 3 日累计），因为 `D1_CLOSE_ADJCHRATE` 是相对当日算的；
  同日同为单日榜时取 `BILLBOARD_DEAL_AMT` 最大者。
* `n_boards` = 去重后的上榜日期数；`fwd[k]` = 该股所有上榜日的后 k 日涨跌幅的均值/胜率/极值（k=1,2,3,5,10）。
* 该指标是**这只票自己的历史**，与「席位画像」是两回事，别混读。

## 三、近期二次分析（`recent_activity.py`）

切分：近 `--recent-days`（默认 5）个交易日 = 近期；窗口内更早部分 = 基线。

| 指标 | 定义 |
|---|---|
| `net_shift` | 近期日均净买入 − 基线日均净买入（万/日） |
| `chg_shift` | 近期上榜股平均涨幅 − 基线（pct，正=更追高） |
| `flip_shift` | 近期一日游比例 − 基线 |
| `bias_shift` | 近期净买倾向 − 基线 |
| `drift` | 风格漂移标签：转打板/转低吸/转一日游/转波段/由卖转买/由买转卖（近期与基线标签集差分） |
| `is_new_face` | 基线 `n_days == 0`（窗口内从未出现）；「稀客」= 基线 ≤ 2 天 |
| `verdict` | 一句话结论：漂移 + 净买变化 + 涨幅变化 + 次日胜率变化（\|Δ\| ≥ 8pct 才提） |

## 四、市场级汇总（`recent_activity.py::market_summary`，仅日报）

* 当日净买入/净卖出 TOP8（按 `TOTAL_NETAMT`）；
* 知名席位动向 = 当日 KB 命中席位，附今日净买 + 涉及股票 + drift + verdict；
* 新面孔 = 非 KB 席位 且（从未出现 或 基线 ≤2 天）且当日买入 ≥ **3000 万**。

## 五、配色口径（`report.py`，`report_stock.py` 复用）

A 股惯例：**涨=红（#ff5a4c）、跌=绿（#22b07d）**。
深色版式，颜色只在 `report.py` 的 `_CSS` 里定义一次。
`report_stock.py` 直接 import 它的 `_CSS` 与格式化工具（`esc/_cls/_pct/_fmt_ratio/_kpi`），
单股报告另加 `_amt_cn`（元→亿/万）与 `_wan_cn`（万元→亿）两个金额人读化函数。
